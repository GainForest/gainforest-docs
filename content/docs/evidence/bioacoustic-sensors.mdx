Bioacoustic monitoring uses sound recordings to understand what is happening in an ecosystem over time.

## What this is for

AudioMoth sensors can record soundscapes from forests, wetlands, farms, restoration areas, or other ecosystems.

These recordings can support:

* biodiversity monitoring
* field research
* environmental education
* community-led stewardship
* Project evidence
* long-term impact reporting

This is useful for teams that want to monitor birds, insects, frogs, bats, or other sound-producing species.

## What you can do on GainForest.app

The bioacoustic sensor tool currently supports **AudioMoth workflows only**.

Users can:

* connect an AudioMoth through the browser
* set the device clock
* configure recording settings
* update firmware
* use auto-setup for field-ready settings
* save a device to an equipment list
* create deployments
* use the acoustic chime during deployment setup
* track where and when a device was deployed
* upload recordings from an SD card or folder
* link recordings to deployments
* save playable previews and spectrograms

## Deployments

A deployment records where and when a sensor was placed in the field. This makes it easier to organize recordings and understand the context behind audio evidence.

Deployment records can help answer questions such as:

* Where was the sensor placed?
* When was it deployed?
* Which AudioMoth device was used?
* Which recordings belong to that deployment?

## Audio as Project evidence

Audio recordings can support biodiversity monitoring, ecosystem storytelling, and evidence-backed conservation work.

Where relevant, recordings or deployment records can be linked to a Project as supporting evidence.

## Grant and capacity building

For communities and local organizations interested in bioacoustic monitoring, GainForest provides support through the Rewilding the Web Grant. The grant can finance capacity building, equipment, and AudioMoth deployment, while the program requires participants to use Bumicerts and related tools such as biodiversity observation uploads and Tainá.

<PageLink href="/opportunities/rewilding-the-web-grant" />

<Callout type="warning">
GainForest does **not currently provide post-data processing** for bioacoustic datasets. If your Project needs species identification, acoustic analysis, or deeper scientific interpretation, it is best to plan for a partner who can support this, such as a local authority, academic institution, researcher, conservation scientist, or biodiversity monitoring expert.
</Callout>
